Train the XGBoost Model

After downloading approved MIMIC-IV, MIMIC-IV-ED, eICU, or labeled hospital exports, save the cleaned CSV in the data folder and train the model from VS Code terminal.

python manage.py train_pud_model data\your_labeled_pud_dataset.csv

The trained pipeline is saved to models\pud_xgboost_pipeline.joblib. Once that file exists, new assessments use the trained model automatically.
